## Step 1 — ATR Calculation (Baseline Volatility)

**File:** `core/smc_engine.py` $\rightarrow$ `calculate_atr(df, period=14)`

All spatial thresholds are dynamic relative to market volatility ($\text{ATR}_{3M}$):

$$\text{TR} = \max\Big(\text{High} - \text{Low}, \, |\text{High} - \text{Prev Close}|, \, |\text{Low} - \text{Prev Close}|\Big)$$
$$\text{ATR}_{3M} = \text{EMA}_{14}(\text{TR})$$

---

## Step 2 — 15M Trend Detection

**File:** `core/smc_engine.py` $\rightarrow$ `detect_15m_trend(df_15m, window=5)`

### Primary Method — Swing Structure
- **BULLISH**: $\text{Swing High}_1 > \text{Swing High}_2 \quad \text{and} \quad \text{Swing Low}_1 > \text{Swing Low}_2$
- **BEARISH**: $\text{Swing High}_1 < \text{Swing High}_2 \quad \text{and} \quad \text{Swing Low}_1 < \text{Swing Low}_2$

### Fallback Method — EMA Crossover
If swing structure is range-bound or range $< 2.0 \times \text{ATR}_{15M}$:
- $\text{EMA}_{20} > \text{EMA}_{50} \quad \text{and} \quad \text{Close} > \text{EMA}_{20} \implies \text{BULLISH}$
- $\text{EMA}_{20} < \text{EMA}_{50} \quad \text{and} \quad \text{Close} < \text{EMA}_{20} \implies \text{BEARISH}$
- Otherwise $\implies \text{SIDEWAYS}$ *(Scan aborted)*

## Step 3 — 3M Order Block Detection

**File:** `core/smc_engine.py` $\rightarrow$ `find_3m_order_blocks(df_3m, trend, atr)`

- **Lookback**: Last 30 3M candles scanned.
- **Impulse Threshold**: $\text{Impulse Move} \ge 1.5 \times \text{ATR}_{3M}$
- **Bullish OB**: Last bearish (red) candle before bullish impulse move.
- **Bearish OB**: Last bullish (green) candle before bearish impulse move.
- **Mitigation Check (`is_ob_still_valid()`)**:
  - Bullish OB is invalidated if any subsequent candle closed below $\text{OB}_{\text{Low}}$.
  - Bearish OB is invalidated if any subsequent candle closed above $\text{OB}_{\text{High}}$.

---

## Step 4 — 3M Fair Value Gap (FVG) Imbalance

**File:** `core/smc_engine.py` $\rightarrow$ `detect_3m_fvg(df_3m, trend)`

- **Bullish FVG**: $\text{Low}_{\text{Candle 3}} > \text{High}_{\text{Candle 1}}$
- **Bearish FVG**: $\text{High}_{\text{Candle 3}} < \text{Low}_{\text{Candle 1}}$

---

## Step 5 — OB + FVG Confluence Check

**Confluence valid if EITHER:**
1. **Overlap**: $\min(\text{OB}_{\text{High}}, \text{FVG}_{\text{Top}}) - \max(\text{OB}_{\text{Low}}, \text{FVG}_{\text{Bottom}}) > 0$
2. **Proximity**: $|\text{OB}_{\text{Mid}} - \text{FVG}_{\text{Mid}}| \le 1.0 \times \text{ATR}_{3M}$

If neither condition is met $\implies$ `Setup lacks FVG confluence`.

---

## Step 6 — Price Action Reaction Triggers

**File:** `core/smc_engine.py` $\rightarrow$ `check_confirmation(df_3m, trend, active_ob)`

1. **Bullish Engulfing**: $\text{Close}_{\text{Curr}} > \text{Open}_{\text{Prev}} \quad \text{and} \quad \text{Open}_{\text{Curr}} < \text{Close}_{\text{Prev}}$ $\rightarrow$ **HIGH Confidence**
2. **Wick Rejection**: Lower wick at OB $> 1.5 \times \text{Body}$ $\rightarrow$ **HIGH Confidence**
3. **OB Midpoint Close**: $\text{Close}_{\text{Curr}} > \text{OB}_{\text{Mid}}$ $\rightarrow$ **MODERATE Confidence**

---

## Step 7 — Risk & Reward Math

### BUY Setup:
$$\text{Entry} = \text{Current Price}$$
$$\text{SL} = \text{OB}_{\text{Low}} - \text{SL\_BUFFER}$$
$$\text{Risk} = \text{Entry} - \text{SL}$$
$$\text{TP1 (1:1.5 RR)} = \text{Entry} + (1.5 \times \text{Risk})$$
$$\text{TP2 (1:2.5 RR)} = \text{Entry} + (2.5 \times \text{Risk})$$

### SELL Setup:
$$\text{Entry} = \text{Current Price}$$
$$\text{SL} = \text{OB}_{\text{High}} + \text{SL\_BUFFER}$$
$$\text{Risk} = \text{SL} - \text{Entry}$$
$$\text{TP1 (1:1.5 RR)} = \text{Entry} - (1.5 \times \text{Risk})$$
$$\text{TP2 (1:2.5 RR)} = \text{Entry} - (2.5 \times \text{Risk})$$

## Signal Validation Matrix

Every signal must pass all data validation checks prior to output:

```
1. direction == "BUY"  → trend_15m must be "BULLISH"
   direction == "SELL" → trend_15m must be "BEARISH"
   (Mismatch → NULL_SIGNAL, TREND_CONFLICT)

2. direction == "BUY"  → SL < Entry, TP1 > Entry, TP2 > TP1
   direction == "SELL" → SL > Entry, TP1 < Entry, TP2 < TP1
   (Mismatch → NULL_SIGNAL, INVALID_SL_OR_TP)

3. Volume check → Volume_3M > 0
   (Volume == 0 → CANDLE_NOT_CLOSED_YET)
```

## No-Signal Reason Code Reference

| Reason Code | Explanation |
| :--- | :--- |
| `CANDLE_NOT_CLOSED_YET` | Volume $= 0$ on last 3M candle (scanning mid-candle) |
| `15M Trend is Sideways` | Market structure is range-bound |
| `No valid Order Block found` | Impulse move did not exceed $1.5 \times \text{ATR}_{3M}$ |
| `OB_ALREADY_MITIGATED` | OB zone was already breached by a subsequent candle close |
| `Setup lacks FVG confluence` | OB and FVG distance exceeds $1.0 \times \text{ATR}_{3M}$ |
| `No confirmation at OB zone` | Price reached zone but no engulfing, wick, or midpoint close triggered |
| `Active trade still running` | Asset already has an active trade open in `active_trades` tracker |
